# Compatibilidades e Incompatibilidades

Esta carpeta documenta incompatibilidades detectadas entre componentes, versiones de BIOS, software o configuraciones.

El objetivo es facilitar la identificación de problemas conocidos y evitar errores repetitivos.

Ejemplos:

- Compatibilidad de memorias RAM.
- Versiones mínimas de BIOS.
- Restricciones de procesadores.
- Compatibilidad entre hardware y software.
