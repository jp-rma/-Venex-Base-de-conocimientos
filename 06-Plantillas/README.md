# Plantillas

Esta carpeta contiene las plantillas utilizadas para mantener un formato uniforme en toda la documentación.

Las plantillas permiten estandarizar la estructura de los distintos tipos de documentos.

Ejemplos:

- Plantilla de procedimiento.
- Plantilla de guía técnica.
- Plantilla de caso RMA.
- Plantilla de checklist.
