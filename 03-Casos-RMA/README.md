# Casos RMA

Esta carpeta contiene casos técnicos relevantes detectados durante procesos de RMA, diagnóstico y soporte.

El objetivo es registrar la evidencia, el razonamiento técnico, la resolución y las acciones preventivas que puedan reutilizarse en futuros casos.

Los documentos no deben incluir nombres de clientes, números de serie, UUID ni otros identificadores que no sean necesarios para comprender el caso.
