# Base de Conocimientos Técnicos

## Descripción

Repositorio destinado a centralizar documentación técnica relacionada con diagnóstico, reparación, armado de equipos y apoyo técnico al área comercial.

Su objetivo es transformar la experiencia obtenida en RMA, soporte técnico y casos reales en conocimiento reutilizable para toda la empresa.

---

## Objetivos

- Centralizar el conocimiento técnico.
- Transformar incidentes y casos de RMA en conocimiento reutilizable.
- Estandarizar procedimientos de trabajo.
- Reducir errores recurrentes.
- Documentar incompatibilidades y buenas prácticas.
- Facilitar la capacitación de nuevos integrantes.
- Brindar material de consulta para las áreas técnicas y comerciales.

---

## Áreas alcanzadas

- RMA
- Taller de Armado
- Soporte Técnico Virtual
- Ventas

---

## Estructura del repositorio

| Carpeta | Contenido |
|---------|-----------|
| 01-Procedimientos | Procedimientos estandarizados de trabajo |
| 02-Guias-Tecnicas | Explicaciones técnicas sobre hardware, software y tecnologías |
| 03-Casos-RMA | Casos relevantes de RMA y las acciones preventivas derivadas |
| 04-Checklists | Listas de verificación para armado, diagnóstico y control de calidad |
| 05-Compatibilidades | Compatibilidades e incompatibilidades detectadas |
| 06-Plantillas | Modelos reutilizables para documentación |
| 07-Imagenes | Recursos gráficos utilizados por la documentación |

---

## Convenciones

Los documentos del repositorio utilizan la siguiente nomenclatura:

- PROC → Procedimientos
- GUIDE → Guías técnicas
- RMA → Casos documentados
- CHK → Checklists
- COMP → Compatibilidades

---

## Filosofía

Cada documento debe responder, al menos, una de las siguientes preguntas:

- ¿Cómo se realiza correctamente una tarea?
- ¿Por qué ocurre un problema?
- ¿Cómo evitar que vuelva a suceder?
- ¿Qué conocimiento puede reutilizar otro integrante del equipo?
