# Procedimientos

Esta carpeta contiene los procedimientos estandarizados utilizados durante las tareas de diagnóstico, reparación, armado, configuración y soporte técnico.

Cada procedimiento busca describir una actividad específica indicando:

- Objetivo.
- Alcance.
- Procedimiento.
- Puntos críticos.
- Buenas prácticas.
- Criterios de incumplimiento.
- Historial de cambios.

Los procedimientos buscan reducir errores, estandarizar tareas y garantizar una ejecución consistente.
