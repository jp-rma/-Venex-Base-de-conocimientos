# Guías Técnicas

Esta carpeta contiene documentación técnica destinada a explicar el funcionamiento de tecnologías, componentes, configuraciones e incompatibilidades.

Las guías no describen procedimientos, sino que buscan facilitar la comprensión de conceptos técnicos utilizados por las distintas áreas de la empresa.

Ejemplos:

- Arquitecturas de procesadores.
- Tecnologías de memoria RAM.
- BIOS y UEFI.
- Conectores de motherboards.
- Interfaces de almacenamiento.
- Tecnologías de refrigeración.
