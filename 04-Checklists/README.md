# Checklists

Esta carpeta contiene listas de verificación destinadas a reducir errores durante tareas repetitivas.

Las checklists deben utilizarse antes, durante o después de una intervención técnica.

Ejemplos:

- Armado de PC.
- Ampliación de notebooks.
- Control de calidad.
- Diagnóstico inicial.
- Entrega al cliente.
